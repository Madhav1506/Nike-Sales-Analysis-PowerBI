Interactive Power BI dashboard featuring sales performance analysis, KPI tracking, product-wise insights, revenue trends, and data visualization using DAX and Excel.

## 📌 Project Overview
This project presents an interactive sales analysis dashboard developed using Microsoft Power BI. It analyzes Nike sales data to evaluate performance, track key metrics, and generate meaningful business insights.

## 🖼️ Dashboard Preview

Nike Sales Dashboard https://github.com/Madhav1506/Nike-Sales-Analysis-PowerBI/blob/main/Dashboard.png

## ✨ Key Features
- 📈 **Sales Performance Analysis** – Analyze overall sales performance.
- 🎯 **KPI Tracking** – Monitor key performance indicators.
- 📅 **Sales Trends** – Explore sales patterns over time.
- 👟 **Product Analysis** – Evaluate product-level sales performance.
- 📊 **Interactive Visualizations** – Explore data through charts and filters.
